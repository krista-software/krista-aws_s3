
# Configuration

For the AWS S3 Extension, 
you would need to obtain access Key and secret Key from AWS portal.

### Steps to get access Key , secret Key and bucket creation 

 * Log in AWS portal from [here](https://aws.amazon.com/console/) as **Root user**.

 * Search **IAM** for creating users.

![Search IAM](../_media/Iam_search.png)


* Click on **Users**.

![Clicking on User](../_media/Click_Users.png)



* Click on **Create user**.

![Creating User](../_media/Creating_User.png)


* Enter **User Name** and click on **Next**.

![Providing User Name](../_media/Provide_UserName.png)


* Click on **Attach Policies Directly**. Select **AmazonS3FullAccess** and then click on **Next**.

![Attaching Policy](../_media/Attaching_Policy.png)



* Click on **Create User**.

![Click on user create](../_media/User_created.png)


*  Click on user you created.

![User Created](../_media/user_created101.png)


* Click on **Create Access Key**.

![AccessKey](../_media/AccessKey.png)

* Click on **Other** and then click on **Next**.

![Others and next](../_media/Others_next.png)

* Click on **Create access key**
* Store access key and secret Key (Download .csv File).

![Optional](../_media/Optional.png)
![CSV File](../_media/CSV_FILE.png)
